# Dariocurr Tap

## How do I install these formulae?

`brew install dariocurr/tap/<formula>`

Or `brew tap dariocurr/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dariocurr/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
